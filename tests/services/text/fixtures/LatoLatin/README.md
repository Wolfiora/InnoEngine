# Text and UI font fixtures

The text and RmlUi behavior tests share these unchanged Lato Latin Regular and Bold fonts. Keeping their test inputs here allows native dependency consumers to run without an initialized third-party source checkout.

Source: `Samples/assets` in RmlUi revision `7a06f27db04fe5d13a5dacc19b2b4544673a4eca`, the repository's pinned upstream revision when these fixtures were adopted. `LICENSE.txt` is copied intact from that directory, including its copyright notices and SIL Open Font License. The fonts are not modified or renamed.
