# Inno.Editor.Shaders.ImGui

[Editor 索引](README.md) · [Wiki 首页](../README.md) · [UI 架构](../architecture/EDITOR_UI_ARCHITECTURE.md)

## 职责与边界

Shader 与 Material 的可复用检查显示。依赖 headless Shaders/Rendering/Assets 以及 Inspection、ImGui；不引用 Inspector 或 ShaderEditor Panel。

## 依赖与初始化

产品通过 `EditorProduct.props` 显式部署此程序集。由当前 TypeRegistry/Editor Registry 发现声明并在候选成功后切换；不扫描目录、不建立独立注册表或全局状态。

## API 与扩展点

ShaderNodeDrawerAttribute、ShaderNodeDrawer、ShaderNodeDrawContext、ShaderNodePresentation 与 registry 描述节点显示；Material inspectors 使用共享草稿；ShaderPropertyInspector 处理参数类型和混合值。ShaderPreviews 只显示当前 preview service 的结果。

## 工作流

扩展继承 ShaderNodeDrawer，Attribute 携带稳定节点 ID。通过 DrawProperty 使用统一属性手势；自定义连续编辑通过当前手势 mergeKey 记录。不要持有 draw context 或 canonical asset。

## 错误、生命周期与热重载

控件只在当前 EditorUiSession 的 owner thread、作用域与原生上下文中使用。跨帧只保留稳定 ID 和中立状态；Missing、只读和未赋值状态保持区别。手势失败保留 History 所有权和诊断；扩展在所属 generation 退休，不保留插件 Type、delegate 或实例。

所有公开签名的当前映射见本页 API 清单；内部实现不构成稳定扩展契约。
